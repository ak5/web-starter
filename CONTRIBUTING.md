# Contributing

Bug reports and focused pull requests are welcome. Include steps to reproduce a
bug and the expected behavior. Keep changes small and update the relevant docs.

See [the contributor guide](docs/development/contributing.md) for setup, checks,
branch conventions, and database migration rules.

For security vulnerabilities, use the private reporting instructions in
[SECURITY.md](SECURITY.md). Do not post credentials or exploitable details in a
public issue.
